## 问题与复验

- 首次 Chromium 检查 3 项失败：两项来自移动返回文案被组件置于 aria-hidden，另一项来自合成 initData 缺少所选 SDK 必填 signature。分别修复语义链接和 fixture 后回归通过；未放宽应用启动校验，也未将合成签名当成身份凭据。
- 延迟路由首屏提示缺少 HydrateFallback，已增加本地化加载态，浏览器回归通过。
- WebKit 首个官方下载地址缓慢；切换官方 CDN 完成下载，安装缺失的本机依赖后双浏览器通过。
- 后续复验出现一次 WebKit 手动创建/关闭额外 context 超时；触控场景改用 Playwright 的 hasTouch fixture 管理上下文，双浏览器 24 项复验通过，未启用自动重试掩盖失败。
- 新启动原始参数与 SDK 结果同时比对 data/version/platform，补充缺失 platform 时不得借旧缓存恢复的单元断言。
- 后台主 JS 约 605 kB（gzip 约 201 kB），保留 Vite 包体提示，未提高阈值隐藏问题；业务增长时按路由拆分及实测优化。当前测试不构成线上性能验收。
