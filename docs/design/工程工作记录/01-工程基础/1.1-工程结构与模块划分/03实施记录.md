## 实际文件与环境

- `backend/go.mod`：module 为 `github.com/0xabcd-k/DexWallet/backend`，Go 最低版本为 1.26.10；没有第三方依赖，因此没有 `go.sum`。
- `frontend/package.json`、`pnpm-workspace.yaml`、`pnpm-lock.yaml`：根包为 `@dexwallet/frontend`；工作区发现 `apps/*` 和未来的 `packages/*`；锁文件由 pnpm 生成，当前四个 importer 均无依赖。
- `frontend/apps/user/package.json`、`merchant/package.json`、`admin/package.json`：三个独立私有包，分别为 `@dexwallet/user`、`@dexwallet/merchant`、`@dexwallet/admin`，未添加应用脚本或源码。
- `frontend/.nvmrc` 固定 Node 24.22.1；packageManager 与 engines 固定 pnpm 10.33.4，Node engines 为 `>=24.22.1 <25`，`.npmrc` 开启 engine-strict。
- `.gitignore` 增加依赖目录、前端构建目录和本地环境文件规则，允许提交无凭据的 `.env.example`。用户原有未跟踪 `.idea/git_toolbox_prj.xml` 未修改、未暂存。
- 新增 [工程结构与基础工具](../../../../engineering/工程结构.md)，同步项目入口、开发规范、决议台账、架构与工作清单；目标领域目录仍由后续真实内容创建。

本机通过 Go 工具链下载准备 1.26.10，通过 nvm 安装 Node 24.22.1，并在该 Node 安装目录安装 pnpm 10.33.4；未改写用户已有 Go/Node 默认版本配置，也未修改 Docker 服务。工具与应用依赖分开管理，当前没有安装 go-zero、goctl、React、Vite 或业务 SDK。
