本轮定位并修正两个 Android 问题：当前 WebView 将自定义 scheme 解析为 opaque path，现改为严格前缀加查询参数解析；初次启动未等待目标懒加载完成，首页重定向会覆盖目标，现启动等待导航完成并添加回归测试。链上码较密，原 320 像素静态解码不稳定，提升到 960 像素。纯 PNG 内容核对用 `PURE_BARCODE`；实际 App 默认解码器另外以九项带背景的测试视频帧验证，不将这两类证据混为一种。

最初新增 UI 测试使用了错误的翻译按钮名称、原生 SDK mock 未命中模块，修正测试边界后通过；未删除行为断言。WebKit 5 项初轮超时分属已有鉴权/后台/余额/启动/占用用例，串行复验通过，没有放宽断言或声称定位浏览器内部原因。测试 API 初次从错误目录启动、模拟器首次遗漏 SDK 环境变量均已更正，失败实例未遗留资源。
