[阶段目录](../README.md) · [全部工作记录](../../README.md) · [工作范围清单](../../../../engineering/工程阶段与工作清单.md)

## 首批验证

- Go 金额用例覆盖固定目标净到账、支付币量进位、18 位资产精度、稳定币偏离 1 美元、Gas 折美元、目标金额格式、Solana 整数溢出及过期边界。四条测试网九个完整资产 ID 均可配置；替代代币配置由其完整合约或 mint 区分。
- 隔离数据库及 Redis 环境通过实际 HTTP 路由验证登录、未配置行情、资产可选标记、有效报价和无效金额。Base Sepolia ETH 测试参数下目标 10.00 美元时，得到 0.0051 ETH、0.20 美元预计费用和 10.00 美元净到账。
- 前端交互验证无可报价资产时可重试、改金额后迟到响应被丢弃、到期撤下金额及测试只读状态。Chromium 和 WebKit 验证 Telegram 的余额充值入口只显示 App 引导，链上目录和报价请求数均为零。Android 调试 APK、普通用户 Web 构建、前端类型检查和单元测试通过。本批没有向链上广播交易，也未使用外部行情作为测试结论。

在 `backend/` 下运行专项验证，HTTP 用例需使用隔离测试环境。

```bash
go test -race ./logic/chainassets ./config -run Deposit
go run ./tools/testenv run go test -race -tags=integration ./api/internal/server -run '^TestProductSessionHTTP$' -count=1
```

## Solana Devnet 原生 SOL 实转核对

2026-11-23（北京时间），使用专用测试账户，按每 SOL 100 美元的测试价试算净到账 0.01 美元。后端经核验 Devnet 创世哈希的公开 RPC 读取区块哈希，对 100,000 lamports 的初始消息及含费 110,000 lamports 的最终消息分别询价，均得到 10,000 lamports。最终消息摘要为 `20902fa62818bd6b405f153dd229adadd05b936ead708cd195e4f3be181fe7d8`。

| 核对项 | 结果 |
| --- | --- |
| 用户支付和收款地址增加 | 0.00011 SOL（110,000 lamports） |
| 平台代付 | 估算 0.00001 SOL，回执实耗 0.00001 SOL |
| 预计费用美元值、预计净到账 | 0.001 美元、0.01 美元，均按上述测试价 |
| 最终确认 | Devnet slot 525127307，执行成功，两份签名均覆盖最终询价消息 |

报价由本轮后端代码生成。独立测试程序核对金额、双方地址、费用支付方及消息摘要后，用测试密钥签名并广播；App 报价接口未执行签名或入账。归档保留两次节点询价、最终序列化交易及回执前后余额，可离线核对。[原始核对数据](../../../../../backend/logic/chainassets/testdata/solana-devnet-deposit-fee.json) · [Devnet 交易](https://explorer.solana.com/tx/4Zq7UGVa6Emop9bCjgpywmSBHj9ZbY3uAFzFwkYpc43yxYGKSidEYChCXHdBd46TuoSowLN3VBU7ZeZ6ka7b4dbo?cluster=devnet)

在 `backend/` 执行 `go test -race ./logic/chainassets -run 'TestSolanaDeposit'` 可复核最终消息摘要、两份签名、预估和实耗、各账户扣增金额，并覆盖 RPC 费用缺失或两次估算不同的失败情形。隔离 HTTP 测试覆盖会话和查询限流，App 交互测试覆盖切换钱包后撤下旧报价、拒收其他钱包的响应。
