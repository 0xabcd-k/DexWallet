## 已有约束与本次调整

沿用 Go/go-zero、MySQL SQL-first、Redis、RocketMQ、三个独立前端产物及平台签名信任边界。2026-10-28 用户指出 worker 与 API 不必物理分开、独立部署增加麻烦，当前方案据此采用一个后端程序/进程同时承载 HTTP 与后台任务；后台任务仍需持久化、有限并发、可恢复。当前代码只有公共基础，尚无业务后台任务。

“无状态”指业务正确性和恢复不依赖某个进程的内存或本机文件，不代表程序不能有连接池、健康快照或缓存，也不代表任意数量副本都安全高效。多副本领取、幂等、会话与资金并发分别随阶段 2、3、5 落实。
