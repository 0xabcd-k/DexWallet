## 2026-11-15 Android 首批

- 新增 `frontend/apps/mobile` 与 Capacitor Android 工程；复用 `apps/user`，native 产物为 `dist-app`。
- 现有账户、任务、奖励、互转与账单复用相同接口，新增可选 CORS 配置及续签头读取。App 邮箱登录可恢复钱包连接页；尚未接入的独立 TG 授权入口显示待接入。
- 原生回跳、前台会话同步与 Android 返回键接入；TON Connect 按产品账户保存、恢复连接，支持两款 TON 外部钱包与名称搜索。回跳不触发业务提交。
- 独立本机 API 夹具使用真实服务、独立数据库、私有验证码文件、100 USD 测试账本和频道 mock 任务。
- Android 关闭备份，调试 HTTP 仅本机，正式构建保护禁止携带 debug 混合内容；构建依赖和 Gradle 校验和入库。

未增加业务迁移，数据库仍为 business 15。未实施内置钱包密钥、链上余额、充值、Gas 或付款；既有真实支付可行性探针保持其独立证据性质。App 构建、配置和安全边界见 [工程说明](../../../../engineering/Android应用基础.md)；执行结果见 [验证记录](04验证记录.md)。
