# 8.4 独立 App 工程 实施方案

[阶段目录](../README.md) · [全部工作记录](../../README.md) · [工作范围清单](../../../../engineering/工程阶段与工作清单.md)

2026-11-15 首批实施范围，依据见 [讨论记录](01讨论记录.md)。

## 目标与步骤

1. 新建 Capacitor Android 壳，复用现有 React 用户端。native 构建使用独立 API 地址、产物和路由；Mini App 不带原生钱包模块。
2. 复用已绑定邮箱、单 JWT、续签与用户 idx。独立 TG 授权待接入，不伪造 Mini App 启动材料。
3. API 增加默认关闭的显式 HTTPS 来源配置，支持原生 WebView 跨域和续签头读取，授权逻辑不变。
4. TON Connect 只连接 Tonkeeper/MyTonWallet，按用户隔离连接材料，支持搜索、取消、断开、切换和恢复。App 回跳只导航，拒绝 URL 中的付款或凭据材料。
5. 用隔离模拟器、真实 API 与本地测试库验证登录、任务和余额；外部钱包只验证连接，不发链上交易。

## 约束与验收

不修改 API/数据库业务契约，无新增迁移。测试账号、验证码、测试钱包及 APK 不入库；Android 备份关闭，HTTP 仅调试本机白名单，release 拒绝 debug 混合内容。未创建内置钱包，因此本批不保存资金助记词或私钥；协议连接存储不是已完成的资金密钥保险库。

验收包括 Android APK 安装启动、真实邮箱登录同一账户、现有任务与余额页面、钱包连接/返回/恢复/断开、无授权的回跳不能登录或付款、Mini App 构建隔离及既有浏览器回归。具体结果和限制见 [验证记录](04验证记录.md)，运行步骤见 [Android 工程说明](../../../../engineering/Android应用基础.md)。

## 后续边界

8.4 首批和 5.1 外部连接不代表完整阶段完成。内置钱包、独立 TG 授权、iOS、商店签名发布及所有链上资金操作分别继续实施；TON、Base、Solana、TRON 四链九组合不缩减。
