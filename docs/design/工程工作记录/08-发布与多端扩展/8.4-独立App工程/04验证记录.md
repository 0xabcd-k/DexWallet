## 问题与复验

| 问题 | 修正与结果 |
| --- | --- |
| WebView 的 localStorage 在强退后未可靠保留刚写入的登录/连接状态 | App 初始化先恢复原生持久状态，业务使用同步缓存；资金请求标识写入完成后才发 API。TON 协议会话单独保存在原生 Preferences；强退恢复已复验 |
| Preferences 插件使用 `apply()`，调用完成不等于磁盘写入成功 | 产品会话/请求改由小型 `NativeState` 插件以 `commit()` 确认落盘；失败阻止后续 API。协议连接仍用 Preferences，可重新授权连接 |
| 将原生初始化放在共同异步入口，影响 Mini App 启动时序 | 原生构建使用独立 `native-main.tsx`，Mini App 保留静态入口；绑定和路由失败用例复验通过 |
| Keeper 目录公布的 `tonkeeper-tc://` 无法唤起实测安装包 | APK 与官方文档核对后使用 `tonkeeper://ton-connect`；实际打开、批准和自动返回通过 |
| 无窗口软件 GPU 的模拟器进程退出 | 软件 GPU 和 host GPU 均曾发生图形上下文错误退出；host GPU 重启后继续验证。该环境问题仍保留，不视为 App 崩溃，也不视为长期稳定性验收 |

原生提交保证参考 [Android SharedPreferences.Editor.commit](https://developer.android.com/reference/android/content/SharedPreferences.Editor#commit())；钱包与构建依据见 [工程说明](../../../../engineering/Android应用基础.md)。卸载、清除数据、设备存储损坏不在本轮恢复保证内。

### 模拟器问题与可复用环境

本轮 37.2.12 使用软件渲染仍在 App 退出/重启附近退出，日志出现 `bad color buffer handle`。官方 Chromium 团队已记录 37.2.x 的 Gfxstream 资源清理/内存问题并回退至 37.1.11，见 [官方变更](https://chromium.googlesource.com/chromium/src/tools/android/+/53a24f44b2957a8937bb63f3d150081c73df0532)。本机现象与其相符，但未取得符号化堆栈，不断言同一根因。

从 [Android 官方归档](https://developer.android.com/studio/emulator_archive) 下载 37.1.11，验证文件大小 **334378080 bytes** 及官方 SHA-256：

```text
95771e0ae431897b2a4bd2d97fa095f29a8b0624a7b216baf529f9306161c266
```

安装到 `.tools/android-app/emulator-37.1.11/emulator/`，系统 SDK 仍保留 37.2.12，没有覆盖用户 SDK 或原有 AVD。本次复现入口：

```bash
ANDROID_HOME=/home/kelizhang/Android/Sdk \
ANDROID_SDK_ROOT=/home/kelizhang/Android/Sdk \
ANDROID_AVD_HOME="$PWD/.tools/android-app/avd" \
.tools/android-app/emulator-37.1.11/emulator/emulator \
  -avd dexwallet_app_api35 -port 5582 -no-window -no-audio \
  -no-snapshot -no-metrics -gpu swangle_indirect -feature -Vulkan \
  -memory 2048 -cores 2 -camera-back none -camera-front none
```

先确认该模拟器和端口未占用；等待 `sys.boot_completed=1`，仅 ADB online 不代表 Android activity 服务已经可用。隔离版本启动与本轮 4 次 App force-stop/重启均完成；这是本次对照结果，不是长期稳定性或所有宿主机兼容保证。后续需要新 manifest 隧道时重新按工程说明构建，不复用已经关闭的临时地址。

自动化注意：钱包按钮可能通过 `content-desc` 提供文字；`uiautomator dump` 可能报告无法等待空闲，必须检查本次导出成功，不能误读上次 XML。连接成功后有的钱包已经直接返回 App，不能把未找到 Done 按钮单独判为连接失败；以当前前台应用、TON Connect 状态、地址与恢复结果核验。
