## 复验命令

```sh
# 仓库根，加载明确的专用测试配置
source .tools/local.env
cd backend
go test -race ./...
go vet ./...
go run ./tools/testenv run go test -p 1 -race -tags=integration ./tests/integration ./api/internal/server -run '^(TestUser|TestAuth|TestProductSessionHTTP)' -v -count=1 -timeout=180s
# frontend/，先按 .nvmrc 切换 Node
pnpm typecheck
pnpm test
pnpm build
pnpm test:e2e
```

全量浏览器首轮 36 项通过，后续只对新增/调整的认证场景复验，不将两次数量相加当作不同测试总数。构建保留后台包既有的 >500kB 提示，不改变依赖或掩盖构建输出；本轮没有引入新的第三方库。
