复验命令（先在仓库根加载专用环境）：

```sh
source .tools/local.env
cd backend
go run ./tools/testenv run go test -race -tags=integration ./tests/integration -run '^(TestUser|TestAuth|TestDependencyClients)' -v -count=1 -timeout=180s
```

运行器已清理该 run 的专属库与逐条登记的准确 Redis key。定时测试覆盖真实 Redis 过期；模拟时钟单测验证精确 30 秒边界，不将轮询观测时间当作 TTL 延长。

按适用范围记录正常、边界、权限、并发、重复请求、失败与恢复；外部真实依赖验证与单元测试分开记录。未执行的检查明确标记，不写为通过。
