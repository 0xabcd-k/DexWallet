## 偏差与遗留事项

- 接口列表补充 totalBalance，由后端对同一账户的可用加占用得到，避免前端另写金额运算，不持久化总额。
- 数据库约束和业务校验共同保护当前种类的非负、精度和占用规则；种类单位与 API 格式定义在 model/account/kind.go。新增种类若改变数据库约束涉及的规则，需同步增量 SQL，不能承诺任意新业务都无需迁移。
- 3.1 不新增余额缓存、注册建账、管理调账或非零资金业务；生成 CRUD 用于基础模型和隔离测试准备，资金模块接入必须走后续统一记账入口。
- business/000004 和 000005 均未应用共享开发库。验证只创建和清理本次受限测试库，部署本版 API 前必须显式升级到 business 版本 5；启动和生成不隐式迁移。
