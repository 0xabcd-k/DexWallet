隔离数据库命令（先载入既有 `.tools/local.env`，不得输出凭据）：

```sh
# backend/
go run ./tools/testenv run go test -p 1 -race -tags=integration ./tests/integration ./api/internal/server -run '^(TestAccount.*|TestUser.*|TestAuthSchemaUpgrade|TestProductSessionHTTP)$' -v -count=1 -timeout=180s
```

浏览器复验在测试子进程中清除 http_proxy/https_proxy/all_proxy 及其大写变量，设置 NO_PROXY/no_proxy 为 127.0.0.1,localhost,::1。实际运行 `pnpm exec playwright test --project=webkit --last-failed --workers=1 --output=test-results/account-retry`，新输出目录下实际选择并通过全部 28 项 WebKit 测试。复现完整复验可直接使用 `pnpm exec playwright test --project=webkit --workers=1`；不修改用户全局代理设置。

## 问题与复验

- 首轮 WebKit 三项失败分别涉及已有跨标签登录、管理端刷新和新增余额页。trace 中均有 Vite 静态模块或 CSS 请求返回 502，页面未加载；测试进程继承了本机代理。清除测试代理并以单 worker 直连重跑后，WebKit 全部通过；未修改业务断言或添加重试掩盖失败。
- 新增 business/000005 后，既有迁移测试改用共享的最新版本常量；专测认证表回滚的测试固定在版本 4，避免误将新增账户表的回滚当作认证表回滚。相关回归通过。

## 验收结论与开放范围

3.1 验收完成：账户模型、精度规则、本人查询和钱包/奖励只读页面可用。浏览器使用明确的 HTTP 测试替身，真实认证与数据库由独立后端 HTTP 集成验证，不将两者描述为浏览器直连真实业务库的全链路测试。

共享开发库仍须显式执行 business/000004、000005 后才能运行本版余额查询；生成与启动不会自动迁移。首次入账竞争、资金幂等、扣款/入账回滚、流水平衡和占用操作尚未实现及验证，归 3.2–3.4。充值、任务、抽奖、奖励转入和链上通道均未由本项开放。
