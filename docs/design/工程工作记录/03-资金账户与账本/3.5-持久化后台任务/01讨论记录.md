## 范围与确认

接续 3.4 内部美元互转，为已提交业务事实建立持久发布、接收去重、任务执行与异常恢复。用户明确“采纳你的意见，执行吧”，据此继续已建议的事务 outbox 与持久任务方案，不重复设置审批关卡。

| 日期 | 议题 | 结论与理由 |
| --- | --- | --- |
| 2026-10-30 | 资金与异步边界 | 单据、账本、事件同事务提交；网络发送在事务外，不让 MQ 成为资金事务的一步 |
| 2026-10-30 | 消费与执行 | 任务持久接收后 ACK，业务结果另由任务状态表达；同事件同处理器去重，发送超时仍沿用原身份 |
| 2026-10-30 | 恢复与运行方式 | 与 API 同进程，有界并发、租约与代次；可重试失败有限重试，结果未知先核实，停止时先排空再关依赖 |
| 2026-10-30 | 本轮业务落点 | 真实内部转账事件与隔离 SQL 处理器验收；通知通道和公开互转流程在所属阶段接入 |

默认并发、时间预算、数据库领取隔离级别及 SDK 修复属于本轮实施选择，依据和限制见 [实施方案](02实施方案.md)，不扩大产品功能。
