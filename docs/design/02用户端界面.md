# 用户端界面

本页给出可直接用于原型的界面规格。页面编号 U01–U17 是设计追踪标识，不是接口路由或数据库枚举。金额和资格按 [业务规则](../product/02业务规则.md) 及 [奖励流程](../product/04任务与奖励.md)，界面不重复定义可变参数。

## U01 钱包首页

从上到下：头像与产品账户、扫码入口；进行中提示；美元可用余额与处理中金额；收款和转账；链上钱包及资产；最近两三笔记录。

余额卡进入 U02；链上钱包区切换当前钱包，资产行进入 U03；收款进入 U04，转账进入 U05。进行中提示进入具体 U10，全部记录进入 U16。

美元余额与链上区域分开，不合并四类资产总额。无钱包时并列提供创建、导入和连接；一个区域加载失败不阻止其他区域查看。

## U02 美元余额详情

展示可用、处理中及占用原因，列表仅列美元相关业务。主操作为充值和转出，分别进入 U07、U08；金额或占用行跳 U10，筛选继承当前账户。

冻结不等于最终扣款；拒绝恢复关联原单。不可用通道说明原因，已存在交易仍可查。美元余额没有助记词备份功能。

## U03 链上资产详情

绑定一个钱包、网络和资产，展示币量、参考美元估值、地址、数据更新时间、收发记录与独立网络费。资产信息可展开完整代币标识。

收款进入 U04 并预选资产；转账进入 U06；充值美元余额进入 U07 并预选来源。切换钱包刷新余额，不能用同名跨链余额凑数。零余额仍可收款，查询失败不显示成零。

## U04 收款

首次进入清楚选择「收到美元余额」或「收到链上钱包」。前者显示头像昵称、账户 idx、账户码和可选金额请求，支持对方余额转账或链上代充值；后者显示钱包、网络、资产、完整地址及收款码。

提供复制、保存、分享、查看收款记录。分享卡片含到账类型，链上卡片同时含网络与资产。拒绝保存权限时保留复制与分享。换目标后更新码，展示二维码本身不产生收入。

## U05 扫码与收款对象

相机取景、相册、粘贴、账户 idx 或订单号查询共用解析流程；结果先展示目标类型与摘要。昵称仅用于辨认，账户按唯一 idx 查找。裸地址缺网络时补选，多个码时让用户选一个。

账户目标进入 U06 或 U07，链上目标进入 U06 或 U08，订单目标进入 U09；已付款订单直接 U10。不支持的码说明原因并提供重扫，不自动执行不明合约或跳任意网址。

## U06 转账

按「给谁 → 金额与来源 → 确认 → 结果」组织，已有扫码上下文时跳过重复输入。目标是美元账户时可选美元互转或链上代充值；目标为链上地址时可选美元出金或用户链上直接转账，相应承接 U07、U08 的业务流程。

确认页始终显示实际收款对象、到账位置、来源、扣款、净到账和费用。「全部」按可用余额及费用计算。只在所选目标支持的方式中切换，不支持个人组合转账。

字段错误就近提示，余额不足显示缺额，不能自转同一美元账户。提交后进入 U10，结果未知不出现「再转一次」。

## U07 充值美元余额

默认受益人为本人；代充值从他人账户码进入，顶部持续显示受益人。选择来源钱包、网络、资产，输入币量或净到账美元；展示费用、汇率、净入账及有效期。

确认充值后签名并进入 U10。更换来源不能覆盖受益账户；切换金额模式重新报价。平台代付说明为从充值金额扣费，不表示免费。手动外部转入仅在通道开通后出现，未验证时不拿普通地址复制替代可靠充值流程。

## U08 转出到链上钱包

展示美元可用金额、目标地址与网络资产、美元扣款、网络费、到账币量以及审核说明。可选本人钱包地址或填写他人地址，不能将他人地址自动标为本人钱包。

提交后进入审核或出款进度；待重报价在 U10 对照新旧到账量确认。拒绝展示恢复金额；未知执行只查询，不再次申请相同出款。提交后地址修改须按原业务安全终止规则处理。

## U09 商户收银台

首屏显示商户、商品、订单金额、有效期与付款组成。美元余额默认优先，可关闭或修改；剩余部分选择一个链上钱包与资产。费用总额在确认前可见，明细在抽屉中展开。

主操作「确认付款」；未提交可返回，不替商户取消订单。余额足够可纯余额支付，关闭余额可纯链上支付。报价、账户或组成变化要求重新确认；新付款不可用时解释原因，既有付款继续 U10。

示例 $10 订单：$3 余额加 $7 对应 TON 网络 USDT，网络费用另列；实际币量按报价。组合先预留余额，再授权链上部分，两部分状态持续可见。

## U10 业务详情与进度

展示业务金额与单位、状态、来源目标、费用、报价版本、时间线和适用链上凭据；按业务只显示相关字段。支付、充值、出金、奖励转入、退款和结算复用结构，具体状态不同。

| 当前状态 | 界面动作 |
| --- | --- |
| 等待授权 | 返回钱包继续或安全退出当前授权 |
| 审核中、确认中 | 查询状态、查看详情、离开；显示最近核验时间 |
| 待重报价 | 新旧结果对比，确认继续；安全条件满足时可终止 |
| 已完成 | 查看账单、复制凭据、返回可信来源 |
| 确定失败 | 说明真实费用和资金恢复，条件满足时重新发起 |
| 待处理 | 查看已收或已退分项、提交说明、查看处理进度 |

组合退款显示「部分已退，其余处理中」，不能隐藏某一分项。申请帮助自动携带业务编号，不要求用户反复输入；已有申请直接展示状态。无链上交易时不展示区块浏览器按钮。

## U11 奖励首页

顶部独立展示待提现奖励、可消费积分和 Pro 进度。主要提示按状态优先引导首任务、检查领奖、积分抽奖或奖励转入，但任务列表与其他可用入口稳定保留。

任务卡片显示本次适用奖励、资格和主按钮；完成首任务后开放次操作「邀请好友完成」。Pro 面板解释来源、永久权益和翻倍生效时点，无购买或领取按钮。

首次结果展示「$1 已进入待提现奖励，Pro 增加 1000」，不写成获得 1000 积分。达到 Pro 与奖励达到 $2 分开显示。

首奖仍在首次任务完成后入账，不在注册或登录时预先显示已入账。内部关于预期任务奖励前置的解释不加入用户文案，继续如实展示首奖及转入条件。

## U12 任务详情与受邀助力

展示任务步骤、有效期、资格、本次奖励和当前状态。主流程为去完成、返回检查并领奖、查看结果；返回保留原邀请上下文，不自动验证为成功。

按任务显示所需外部身份及当前绑定状态；缺少时提供「绑定 Telegram」等明确入口，保留任务和邀请上下文，绑定返回后重新查询资格。次数展示对应外部身份，首奖与奖励余额展示对应产品用户；换绑不宣传为重置次数或重新获得首奖。未依赖外部身份的任务不显示无关绑定门槛。

受邀页补充邀请者和双方收益。老用户开始前醒目说明本人无奖励且占用参与资格，提交时再次确认；新用户说明首奖及完成后建立关系。本人打开自己的链接返回任务页。

已领奖显示原结果与记录；校验未满足显示具体缺项，超时先查原请求；到期、资格耗尽和邀请失效说明原因，保留其他任务入口。

## U13 积分抽奖

展示可消费积分、待提现奖励、单次结果和历史入口。主按钮「100 积分转一次」，积分不足明确缺额并引导任务；规则面板展示生效版本全部奖项与概率。

提交中防重复，结果确定后再播放动画；离开重进能看到原结果。普通结果短反馈，大额结果可增加视觉反馈，不承诺固定次数中奖，不提供自动连转或充值买积分入口。

## U14 奖励转入美元余额

展示待提现奖励、申请中金额、申请金额、固定本人到账账户、手续费 0 及条件清单。满足条件可选全部并确认，不填写链上地址。

不满足条件列出缺项、当前值和具体路径，没有操作路径时说明等待原因。提交进入 U10；拒绝退回显示原记录，可重新申请但重新核验，不重复处理原单。

## U15 邀请成果

概览显示绑定好友数、有效助力数、助力任务积分、20% 分成；页内按好友与收益查看，支持日期和类型筛选。好友详情按直接助力、长期分成分别列记录。

「选择任务邀请」返回任务列表再生成具体链接。未完成首任务显示首次完成引导；空列表和筛选无结果分开。没有通用邀请链接或改绑上级入口。

## U16 记录

标签为全部、美元余额、链上资产、待提现奖励、任务积分；筛选类型、方向、时间与状态，支持有权限的订单号精确定位。记录行展示对象、时间、金额单位、方向和状态。

点击进入 U10，关联资金变动按主业务聚合。失败返还不标成赚取奖励，冻结不标成最终消费。空态提供钱包或奖励入口；筛选取消保留原结果，重置与应用明确区分。

## U17 身份与钱包管理

| 子流程 | 展示与操作 | 恢复与边界 |
| --- | --- | --- |
| 登录 | Mini App 静默鉴权；App 仅邮箱、Telegram 两种入口 | 成功回来源业务；失败可重试或选择另一入口，不回退为设备登录 |
| 外部身份绑定 | 展示功能所需身份、绑定状态和缺失原因，按需完成验证 | 返回原操作并重查资格；绑定数量、冲突与换绑流程待确定 |
| 账户与帮助 | 昵称、idx、身份来源、语言、帮助、反馈、适用登出 | 登出不取消交易；反馈关联业务，不自动退款 |
| 钱包管理 | 内置及外部分组、网络地址、默认选择、备份或会话状态 | 切换刷新链上资产，不切换产品账户或登录状态；断开不删记录 |
| 创建内置钱包 | 名称、本机解锁、助记词备份、备份核对、完成 | 本地密钥方案按客户端验证，后端不接收密钥 |
| 导入钱包 | 支持格式输入、校验、展示可恢复账户 | 不覆盖已有钱包，不承诺任意助记词恢复所有链账户 |
| 连接外部钱包 | 按当前网络与能力打开官方选择器，同设备授权返回 | 无品牌白名单，无跨设备配对；拒绝保留原表单 |
| 备份或移除 | 备份查看需本机解锁，移除明确仅删除本机访问 | 确认已备份，不宣称后端能够恢复密钥 |

缺钱包时允许改用外部钱包，不强迫完成内置创建。授权返回失败可手动切回并继续原业务；会话过期需重连，用户主动断开后不自动重连。

邮箱登录用户除操作必要条件外可使用功能，不统一要求先绑定 TG。登录页不提供直接登录、游客登录或钱包登录；后续实现时文案纳入国际化资源。本页仅更新设计，不表示登录界面或接口已实现。
