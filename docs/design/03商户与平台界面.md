# 商户与平台界面

后台以桌面列表、持久详情和抽屉组织。登录布局可共用，账户入口和数据权限分开；登录失效后恢复原页面并重新校验允许动作。业务依据见 [商户与平台](../product/05商户与平台.md)。

## 商户端

侧栏采用工作台、订单、资金与结算、接入与设置；企业与商户资料在主体入口维护。创建收款单作为工作台和订单列表的显著按钮，不占一个低频常驻导航。

| 编号与界面 | 主要展示 | 主要操作 | 关键状态 |
| --- | --- | --- | --- |
| M01 开通与主体资料 | 企业资料、商户用途、联系人、申请版本、启用状态 | 创建商户、提交、补充资料、查看原因 | 未提交、审核中、退回、启用、暂停 |
| M02 工作台 | 今日支付金额与笔数、待付订单、退款中、可结算、近期异常 | 创建收款单、进入携带筛选的列表 | 无订单引导首单，未启用说明原因 |
| M03 订单列表 | 日期、平台及商户订单号、支付与退款状态、金额、回调状态 | 查询、重置、详情、导出当前范围 | 空列表与无匹配区分；导出生成及失败可查 |
| M04 订单详情 | 商品、金额、付款组成、实收、费用、退款分项、通知与异常时间线 | 分享有效订单、申请关闭、退款、重试通知、申请处理 | 未开始可关闭；在途继续核验；未知不强制成功 |
| M05 创建收款单 | 商品标题、美元金额、商户订单号、备注、有效期、可用方式 | 确认创建、复制链接、保存码、查看订单、再建一单 | 同号同参返回原单，异参冲突；创建不代表收入 |
| M06 资金与结算 | 可结算、退款及结算占用、流水、结算记录、原币与美元 | 申请结算、筛选导出、详情、确认新报价 | 资金不足、待审核、待备付、待重报价、确认中、已结算 |
| M07 接入与设置 | 通道、费率、凭据摘要、回调、返回地址、结算资料版本、接口说明 | 保存、凭据轮换、测试通知、复制示例 | 校验失败就近说明，新凭据受控展示 |

### 订单与结算详情

支付、退款、通知分别显示，不用通知失败代替未支付。退款确认展示原来源、可退上限、费用和原因；资金不足进入待补资，不能让用户以为已退款。

结算申请展示美元占用、目标地址版本、资产、费用和净到账。提交确认后冻结可结算金额；结算详情可独立打开，展示审核、执行、链上确认和完成。更换资料不改既有单据目标。待重报价展示新旧结果，由商户确认后继续。

统计指标说明时区、是否含处理中金额与当前商户范围。商户暂停后仍可查看和处理既有资金。关闭详情恢复列表筛选，不把长时间处理状态只放在临时弹窗里。

## 平台端

平台首页优先显示待办，再展示资金与运行摘要；后台诊断信息保留必要上下文，按权限区分内部信息与用户可见说明。

| 编号与界面 | 主要展示 | 主要操作 | 边界 |
| --- | --- | --- | --- |
| P01 待办工作台 | 审核、异常实收、未知出款、回调、超时、通道及对账问题 | 按类型与等待时长进入处理详情 | 统计只汇总，资金操作进入具体记录 |
| P02 用户管理 | idx、外部身份、状态、四类账户、Pro、邀请与业务记录 | 查询、详情、限制或恢复交易范围 | 无直接改余额、积分、上级或奖励撤销 |
| P03 企业商户管理 | 企业归属、商户资料、启用申请、费率通道、订单结算 | 审核启用、退回、暂停新交易、恢复、主账户恢复 | 停用不删除历史；费率按版本生效 |
| P04 任务与奖励管理 | 已实现任务类型、多语言内容、资格、积分、有效期、奖项版本 | 草稿、预览、校验、发布下架、查看完成记录 | 新类型需开发，不能上传任意代码 |
| P05 审核队列与详情 | 申请类型、主体、金额、占用、风险统计、目标与报价 | 通过、拒绝、要求补充，写原因 | 通过不等于到账，未知出款不再次执行 |
| P06 异常处理详情 | 应收实收、转账事件、分配、分项状态、重试与错误、证据 | 重新查询、关联、补记、退款、通知重试、暂挂 | 无证据不补成功，暂挂保留责任和下次处理时间 |
| P07 资金执行与对账 | 用户负债、商户应付款、项目原币资产、出款占用、在途、差异 | 对账、受控结算执行、归集调拨、导出 | 无任意打款万能入口，导出提案计入在途 |
| P08 参数配置 | 通道、行情、费用限额、风险、订单、通知和版本差异 | 保存草稿、校验、预览影响、发布、暂停或恢复 | 规则校验失败不可发布，已发生资金不随回滚配置撤销 |
| P09 操作记录 | 操作者、对象、时间、前后值、原因、结果、关联业务 | 筛选、只读详情、授权导出 | 成功失败都保留，不可编辑删除历史 |

### 集中处理详情

同一工作区域展示对象摘要、资金和占用、外部证据、业务时间线、已执行动作、允许操作。跳转到关联用户或商户后能返回原待办。

确认资金动作时展示影响预览、实际目标、金额、费用与原因。后端以状态版本校验，处理冲突刷新原记录。输出「已受理」「待执行」「已提交链上」「已确认完成」分别对应事实。

拒绝奖励转入退待提现奖励，拒绝用户出金释放美元冻结，拒绝商户结算释放商户可结算金额；只有确定尚未执行才能释放。出款未知只提供查询和处理入口，不能同时退占用并发新交易。

### 后台登录与恢复

展示后台类型、邮箱、密码和邮箱验证码，密码与验证码必须都通过才能登录，不提供二选一入口。错误时保留邮箱，不在只验证密码后显示登录成功。临时密码首次登录须修改。管理端用户只由服务器 super 工具创建，管理端页面提供商户用户创建；企业申请不自动意味着公开后台注册。

登录后敏感操作前的再次验证属于另一项规则，本轮已确认延期；不能将其与必需的邮箱验证码登录混淆。

普通退出清理当前端凭证，不单独撤销服务端某次登录；身份失效不清除服务器任务。恢复渠道按后台角色提供，不向商户显示平台管理信息。后台入口隐藏不能替代接口权限。
