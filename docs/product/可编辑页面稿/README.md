# 可编辑页面稿

用 Word 或 WPS 打开 `.docx`，直接修改表格中的文字、按钮和区域位置。每个页面单独一份文件，按用户端、商户端和平台端分目录。

【文字】表示按钮，普通文字表示展示字段，下划线表示输入框。上下排列对应页面的上下位置，横向单元格对应并排布局；后台左栏表示导航。部分页面另附一页弹窗布局。

从 [Word 页面目录](00页面目录.docx) 进入，也可直接打开下列文件。页面稿作为后续修改的工作文件，保留你的直接编辑，不自动覆盖。
