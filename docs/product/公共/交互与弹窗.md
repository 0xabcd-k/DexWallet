# 公共交互与弹窗

页面正文只描述自己使用的弹窗，具体共性以此文档为准。弹窗不列为独立页面，手机端优先使用底部抽屉，后台优先侧栏或居中对话框。

## 通用组件

| 组件 | 展示 | 操作 |
| --- | --- | --- |
| 钱包选择抽屉 | 钱包名称、类型、网络、缩略地址、连接状态 | 选择钱包；管理钱包；连接外部钱包；关闭；选择后刷新余额和费用 |
| 资产选择抽屉 | 币种、网络、余额、可用状态 | 搜索、筛选网络、选取；不可用项说明原因；不能把同名币跨链合并 |
| 金额与费用说明 | 转出或支付金额、平台费用、网络费、到账量、报价有效期 | 确认；返回修改；报价变化后重新确认 |
| 地址或收款账户确认 | 链上地址与网络，或产品昵称与账户 ID | 复制；返回修改；继续；账户类型明确 |
| 规则说明 | 当前生效规则、适用范围与更新时间 | 关闭；长内容可滚动；任务规则、Pro、积分和费用分别说明 |
| 账单筛选抽屉 | 账户、类型、收支方向、状态和日期 | 重置；应用；取消，不立即清空原结果 |
| 处理中状态 | 当前阶段、已完成步骤、下一步说明 | 查看记录；刷新状态；返回；不显示重复提交按钮 |
| 结果反馈 | 成功、失败或待处理原因，实际变化的账户和金额 | 完成；查看详情；按状态重试或联系处理 |
| 放弃未提交表单 | 未提交内容将丢失 | 继续填写；放弃；已提交交易不使用此弹窗撤销 |
| 后台操作确认 | 对象、金额或变更内容、影响范围、原因输入 | 确认操作；取消；资金类操作提交后进入结果查询 |

## 状态与返回规则

- 加载金额时显示占位，失败时显示重试；未知余额不显示为零。
- 无记录显示空状态和有用入口；筛选无结果可清除筛选。
- 禁用按钮必须同时给出原因，如余额不足、未达提现条件、网络暂不可用。
- 表单在发出请求后防止重复提交；网络超时先查询原记录。确认失败且未提交时才允许重新发起。
- 取消外部钱包授权返回原表单；已经广播的交易继续查询，不能显示为已撤销。
- 断开钱包只结束连接，不删除历史账单；换钱包后旧钱包交易仍可查看。
- 原生币网络费和代币数量分别显示，不把不同币种的数字直接相加。
- 用户页普通二级页面有返回，外部链接直达时有明确回首页入口。后台抽屉关闭后保留列表筛选。
- 所有对外文案进入国际化资源；时间用用户时区，金额始终显示单位。

## 二维码的边界

首版保留链上收款码、产品账户收款码、商户订单支付码。扫码入口识别业务类型后进入对应页面，未知格式说明原因，不自动访问任意链接。普通地址缺少币种或网络时让用户选择并确认。

外部钱包连接只做同设备唤起，不提供跨设备配对二维码或复制配对链接。业务收付款二维码不属于被暂缓的跨设备连接功能。
