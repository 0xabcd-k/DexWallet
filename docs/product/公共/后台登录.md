# 后台登录

[打开可编辑页面稿（Word / WPS）](../可编辑页面稿/公共/后台登录.docx)

页面类型：独立页面，商户后台和平台管理后台复用布局、分开账户入口。

## 用途与入口

从对应后台网址进入；登录失效时返回此页，成功后恢复原页面。用户端登录不在这里处理。

## 页面展示

- 标题明确“商户后台”或“平台管理后台”，显示项目名称。
- 账户、密码输入框，密码显示切换；需要二次验证时展示验证码输入步骤。
- 登录错误、账户停用或会话过期说明，不展示不存在的业务数据。

## 按钮与跳转

| 按钮 | 行为 |
| --- | --- |
| 登录 | 验证身份，进入对应工作台或原页面 |
| 显示密码 | 切换输入可见性，不改变内容 |
| 无法登录 | 展示账户恢复渠道；商户联系平台，平台使用已配置的管理账户恢复方式 |
| 验证并继续 | 完成当前账户要求的二次验证 |

## 弹窗与抽屉

“无法登录”显示恢复说明和关闭按钮。首次开通的临时凭据在登录后进入修改密码弹窗，输入原密码、新密码和确认密码。

## 状态与边界

登录中禁止重复提交；失败保留账户名，允许重新输入凭据。首版管理账户由平台开通，不增加公开后台注册入口。管理端的权限校验独立于界面隐藏。
