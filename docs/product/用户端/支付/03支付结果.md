## 用途与入口

从提交付款、扫码已处理订单或账单重新进入。可恢复查看支付结果，不依赖用户停留本页。

## 页面展示

- 大状态：处理中、支付成功、未完成、待人工处理、退款处理中或已退款。
- 商户与订单摘要、美元及链上两部分各自的进度、实际扣款和退款金额。
- 链上确认与商户通知分开显示，到账成功而商户通知失败时不让用户再次支付。

## 按钮与跳转

| 按钮或操作 | 行为与去向 |
| --- | --- |
| 查看账单 | 进入[账单详情](../记录/02账单详情.md)。 |
| 刷新状态 | 查询当前订单，不重新发起交易。 |
| 返回商户／返回钱包 | 有可信商户返回入口时使用；否则回钱包。 |
| 重新选择付款方式 | 仅确定未付款且订单有效时回[支付确认](02支付确认.md)。 |
| 申请处理 | 异常时进入账单中的处理申请入口，自动带上订单信息。 |

## 弹窗与抽屉

- 状态说明抽屉解释等待链上确认、余额处理或人工审核的当前阶段。
- 处理申请弹窗填写问题说明，已有申请时展示进度而非重复创建。

## 状态与边界

- 过期到账、少付、多付和部分付款进入待处理，不把部分收到的钱写成整单成功。
- 退款原资金来源分别展示，平台美元退回与链上退款可能不同步。
- 关闭页面不取消已发起付款；链上结果不明时没有“再付一次”按钮。
