# 支付确认

## 用途与入口

从扫码、订单号查询或商户支付入口进入。主任务是看清给谁付、用哪些资金以及实际扣多少。

## 页面展示

- 商户名称、订单标题、平台订单号、商户订单号、美元金额和有效期。
- 美元余额使用开关与金额；默认先用可用余额，允许手动减少或全部关闭。
- 剩余链上付款部分：付款钱包、网络、币种、预计数量、汇率、网络费及报价倒计时。
- 完整支付组成，例如 10 美元订单＝3 美元余额＋等值 7 美元的 TON USDT，费用另列。

## 按钮与跳转

| 按钮或操作 | 行为与去向 |
| --- | --- |
| 使用美元余额／修改金额 | 调整美元部分，重新计算链上差额。 |
| 付款钱包／链上资产 | 打开选择抽屉；只保留一个钱包、网络和资产。 |
| 刷新报价 | 报价过期后重取并展示变化。 |
| 确认付款 | 复核当前组成，先预留美元部分，再完成链上授权；纯美元付款直接处理。 |
| 暂不支付 | 未提交时返回来源页，不替商户取消订单。 |

## 弹窗与抽屉

- 费用说明抽屉分别解释订单金额、网络费和平台费。
- 报价变化弹窗展示新旧数量，必须重新确认。
- 离开未提交表单可确认放弃；外部钱包签名由钱包软件完成。

## 状态与边界

- 余额足够时允许纯美元支付；关闭美元开关可纯链上支付。
- 不跨链、跨钱包合并资产；数据变化后重新校验余额及费用。
- 用户拒绝且确认没有链上交易时释放美元预留；已广播或结果不明进入[支付结果](03支付结果.md)继续查询。
- 过期或暂停通道禁止新付款；重复点击返回原付款记录。
