## 用途与入口

底部“邀请”一级页，查看直接邀请关系、好友助力贡献和长期分成。

## 页面展示

- 已绑定好友数、有效助力次数、助力所得积分、20% 分成所得积分分别展示。
- 好友列表显示昵称、绑定时间、贡献摘要；收益明细显示来源、时间、积分和到账状态。
- 筛选支持最近 7 天、30 天及自选时间，不把好友数与助力次数混为一项。

## 按钮与跳转

| 按钮或操作 | 行为与去向 |
| --- | --- |
| 好友／收益明细 | 切换页内标签。 |
| 好友行 | 打开好友贡献抽屉，查看此好友的关系及收益记录。 |
| 选择任务邀请 | 进入[任务列表](../任务/01任务列表.md)，由具体任务生成链接。 |
| 收益行 | 进入[账单详情](../记录/02账单详情.md)。 |
| 筛选 | 选择日期及收益类型。 |

## 弹窗与抽屉

- 好友贡献抽屉展示直接助力与分成两类记录，不提供修改关系操作。
- 邀请说明弹窗解释有效助力和长期分成是两种收益。

## 状态与边界

- 新用户未完成首个任务时只显示完成首个任务的引导，不提供邀请或复制链接。
- 空列表引导先选择可邀请任务；不生成不关联任务的通用邀请链接。
- 关系建立后用户侧不可变更；分成积分不计 Pro 进度。
