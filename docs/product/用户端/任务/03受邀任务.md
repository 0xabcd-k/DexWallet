# 受邀任务

[返回产品目录](../../README.md) · [公共交互](../../公共/交互与弹窗.md)

## 用途与入口

用户打开任务邀请链接直接进入，不先跳钱包首页。页面复用任务步骤，补充邀请者与本次参与说明。

## 页面展示

- 邀请者昵称、任务标题、操作步骤、是否有参与资格。
- 新用户明确显示首次本人完成可得 1 美元，完成后建立直接邀请关系。
- 老用户明确显示本次助力本人无奖励，且消耗该任务参与资格；邀请者获得任务积分。

## 按钮与跳转

| 按钮或操作 | 行为与去向 |
| --- | --- |
| 去完成任务 | 打开任务执行入口，返回继续本页。 |
| 完成并助力 | 主动验证完成情况，成功后显示双方适用结果。 |
| 查看我的任务 | 进入[任务列表](01任务列表.md)。 |
| 查看奖励 | 仅本人实际获奖时进入相应账单。 |

## 弹窗与抽屉

- 老用户首次提交本次助力前确认“本人无奖励、占用参与资格”，按钮为继续助力和返回。
- 结果弹窗分别显示已助力、本人首奖及后续入口，不承诺给老用户发奖。

## 状态与边界

- 本人打开自己的链接直接返回任务页，不生成助力。
- 关系只在首次任务通过邀请页完成时绑定；已绑定用户助力他人不变更上级。
- 任务失效、已使用资格或邀请无效时显示原因，保留查看任务入口。
- 同一次验证只计一次完成；接受有效助力的次数不设页面上限。
