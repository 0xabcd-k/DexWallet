# 奖励提现

[返回产品目录](../../README.md) · [公共交互](../../公共/交互与弹窗.md)

## 用途与入口

从任务页或 Pro 页进入，将待提现奖励转到本人美元余额。

## 页面展示

- 待提现奖励、处理中金额、申请金额、固定到账位置“本人美元余额”。
- 条件列表显示 Pro、最低 2 美元及当前启用的其他条件是否满足。
- 手续费为 0，到账美元等于申请美元；展示最近申请记录。

## 按钮与跳转

| 按钮或操作 | 行为与去向 |
| --- | --- |
| 全部／提交提现 | 选择金额，满足条件后确认申请。 |
| 去完成条件 | 跳到明确可完成的任务或 Pro 页面；没有操作路径时展示原因。 |
| 查看记录 | 进入本次[账单详情](../记录/02账单详情.md)。 |
| 返回任务 | 回[任务列表](01任务列表.md)。 |

## 弹窗与抽屉

- 提交确认弹窗展示金额、固定到账账户、费用 0 及可能的审核状态。
- 条件说明弹窗展示当前规则，不要求填写链上钱包地址。

## 状态与边界

- 提交后扣除待提现余额并生成记录，自动处理或进入人工审核。
- 拒绝时退回待提现余额，可在满足条件后重新申请。
- 既有申请状态不明时查询原记录；奖励提现与美元余额链上提现的限额和费用不混用。
