## 用途与入口

从任务列表进入，承担本人执行任务和主动检查领奖。

## 页面展示

- 任务标题、说明、步骤、有效期、剩余参与资格与本次奖励。
- 本人当前状态：可参与、待完成、校验中、已领奖、不可参与。
- 已完成时显示本次积分或首奖、Pro 进度变化，以及对应记录。

## 按钮与跳转

| 按钮或操作 | 行为与去向 |
| --- | --- |
| 去完成任务 | 打开该任务指定的操作入口，返回后保留当前任务。 |
| 完成领奖 | 调用当前任务的验证流程，成功后自动入账并展示结果。 |
| 邀请好友做任务 | 已完成首个任务的用户可打开本任务邀请抽屉。 |
| 查看奖励记录／返回任务 | 进入[账单详情](../记录/02账单详情.md)或[任务列表](01任务列表.md)。 |

## 弹窗与抽屉

- 成功结果弹窗列出本次获得金额或积分；触发 Pro 时补充权益已生效。
- 邀请抽屉仅生成此任务链接，展示复制及分享操作。
- 规则说明弹窗展示该任务独有的完成条件和资格。

## 状态与边界

- 验证失败显示尚未满足的条件，允许任务规则支持的重试；超时查询当前领奖结果。
- 同一次完成不能重复领奖；首次任务奖励只发一次。
- 新用户没有邀请操作；任务到期或资格耗尽时按钮禁用并说明原因。
