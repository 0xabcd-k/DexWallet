## 用途与入口

底部“任务”一级页；展示可做任务、积分消费入口和奖励提现进度。

## 页面展示

- 顶部三个独立区域：任务积分、待提现奖励、Pro 累计进度。
- 任务卡显示标题、条件摘要、有效期、参与资格和本次预计奖励。
- 新用户卡片突出首次完成得 1 美元；老用户按本人 Pro 状态展示任务积分，翻倍来源可解释。
- 标签为可参与、已完成，任务列表支持刷新。

## 按钮与跳转

| 按钮或操作 | 行为与去向 |
| --- | --- |
| 任务卡／去完成 | 进入[任务详情](02任务详情.md)。 |
| 邀请好友做任务 | 仅首次任务完成后展示，打开当前任务邀请抽屉。 |
| 转水果机 | 进入[水果机](04水果机.md)。 |
| 奖励提现 | 进入[奖励提现](06奖励提现.md)。 |
| Pro 进度／奖励记录 | 进入[Pro 权益](05Pro权益.md)或对应[账单列表](../记录/01账单列表.md)。 |

## 弹窗与抽屉

- 任务邀请抽屉展示任务标题、对方参与条件、分享文案，提供 Telegram 分享及复制任务链接。
- 奖励规则弹窗区分首奖、普通积分和 Pro 翻倍。

## 状态与边界

- 新用户只有本人做任务入口，不显示邀请按钮；已绑定邀请关系不影响查看任务。
- 每类任务控制参与次数与资格，页面不把“已完成”默认当作所有任务永久不可参与。
- 积分不足不影响做任务；待提现奖励不足不影响已有积分转动。
