# 水果机

[返回产品目录](../../README.md) · [公共交互](../../公共/交互与弹窗.md)

## 用途与入口

从任务列表积分区进入，使用任务积分获得待提现现金奖励。

## 页面展示

- 顶部展示可用积分和待提现奖励，三列图案位于中心。
- 主按钮明确“100 积分转一次”；展示本次奖励及最近个人记录。
- 规则入口展示生效版本的奖项、概率和现金去向；原型采用候选档位。

## 按钮与跳转

| 按钮或操作 | 行为与去向 |
| --- | --- |
| 100 积分转一次 | 一次请求确定结果与入账，动画展示已确定结果。 |
| 规则／中奖记录 | 打开概率规则弹窗，或进入筛选后的奖励账单。 |
| 继续转一次 | 上一次结果确定后才可再次操作。 |
| 去做任务／奖励提现 | 积分不足时到[任务列表](01任务列表.md)；提现到[奖励提现](06奖励提现.md)。 |

## 弹窗与抽屉

- 结果弹窗显示获得美元及待提现余额，提供继续和关闭。
- 规则弹窗列出每档金额与概率，不使用“转够次数必中奖”的文案。

## 状态与边界

- 不足 100 积分不能转；处理中按钮禁用，不自动连抽。
- 离开、动画中断或响应丢失后恢复原结果，不能重新抽取或重复扣分。
- 消耗积分不减少 Pro 进度，现金奖励不增加 Pro 进度。
- 无奖励撤销入口；未提交事务的失败回滚仍保留。
