## 用途与入口

从钱包或任务页的 Pro 状态进入，解释解锁条件和当前权益。

## 页面展示

- 未解锁显示累计进度／2000、进度条和达到条件后自动解锁的说明。
- 进度来源区分首次 1 美元对应 1000 进度、本人任务积分、好友助力积分；20% 分成不计进度。
- 已解锁展示永久生效、后续任务积分翻倍，以及提现仍受金额和动态条件约束。

## 按钮与跳转

| 按钮或操作 | 行为与去向 |
| --- | --- |
| 去做任务 | 进入[任务列表](01任务列表.md)。 |
| 查看进度来源 | 打开进度明细抽屉并可进入相关账单。 |
| 查看提现条件 | 进入[奖励提现](06奖励提现.md)。 |
| 规则说明 | 展示翻倍生效时点与不计入项目。 |

## 弹窗与抽屉

- 进度来源抽屉按日期显示增加原因和数量。
- 权益说明弹窗明确触发解锁的当笔不翻倍，用户消费积分不降级。

## 状态与边界

- 不存在购买 Pro 或手动领取解锁按钮。
- Pro 进度与可消费积分分别显示，不把首次 1000 进度标成到账积分。
- 上级自身 Pro 不再次放大邀请分成。
