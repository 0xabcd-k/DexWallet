# 账单详情

[返回产品目录](../../README.md) · [公共交互](../../公共/交互与弹窗.md)

## 用途与入口

从账单、支付结果、充值、提现或任务结果进入；一套详情模板按业务类型显示内容。

## 页面展示

- 顶部金额单位、方向、类型与状态；业务编号、创建时间及完成时间。
- 按类型展示资金来源和去向、网络资产、费用、报价、交易凭据、对方或任务。
- 处理中时间线展示申请、审核、发送、到账等适用步骤。
- 奖励记录列出本人任务或好友助力所得、分成、Pro 进度变化；内部转账列出账户双方。

## 按钮与跳转

| 按钮或操作 | 行为与去向 |
| --- | --- |
| 复制编号／地址 | 复制对应信息，不混淆订单号和交易凭据。 |
| 查看链上交易 | 打开与网络匹配的区块浏览器；无链上交易时不显示。 |
| 查看关联记录 | 在提现转入、付款与退款等相关记录之间跳转。 |
| 刷新状态 | 仅查询原记录。 |
| 重新确认报价 | 审核通过后报价失效的出金记录打开报价复核弹窗。 |
| 申请处理／处理进度 | 提交问题描述或打开已有处理记录。 |

## 弹窗与抽屉

- 处理申请弹窗包含问题类型和说明，自动带上当前记录。
- 报价复核弹窗展示新的币量和费用，确认后继续同一申请；不接受时可按尚未发出规则撤回并退回余额。

## 状态与边界

- 确定失败后才展示重新申请或退回结果；结果未知不显示可重复提交操作。
- 人工处理结果说明实际资金变化；只允许查自己的记录。
- 页面仅展示当前业务所需字段，不堆放所有交易类型的空字段。
