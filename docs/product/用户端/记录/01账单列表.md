# 账单列表

## 用途与入口

从钱包首页、任务奖励、邀请收益或具体资产页进入；呈现用户资金与积分的统一查询入口。

## 页面展示

- 顶部账户标签：全部、美元余额、链上资产、待提现奖励、任务积分。
- 按日期分组的记录：类型、对方或来源、时间、金额单位、方向和状态。
- 筛选摘要显示当前时间段、状态和类型；账户内部转移可展开查看关联记录。

## 按钮与跳转

| 按钮或操作 | 行为与去向 |
| --- | --- |
| 筛选 | 打开账户、类型、日期、状态、方向筛选抽屉。 |
| 记录行 | 进入[账单详情](02账单详情.md)。 |
| 清除筛选／加载更多 | 恢复默认范围或继续读取记录。 |
| 搜索订单号 | 输入平台订单号或商户订单号精确定位，不做全量模糊搜索。 |

## 弹窗与抽屉

- 筛选抽屉有应用、重置、取消。
- 订单号搜索弹窗有输入、查询和关闭。

## 状态与边界

- 不把美元、代币和积分相加；展示合计时只针对同一账户和单位。
- 冻结不显示成最终支出；失败退回与原记录关联，不伪装成收入奖励。
- 列表为空显示去做任务或返回钱包；筛选无结果提供清除条件。
