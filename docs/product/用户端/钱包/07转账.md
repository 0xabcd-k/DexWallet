## 用途与入口

从钱包首页、资产详情或识别收款码进入，链上转账与美元账户转账共用一个表单页面。

## 页面展示

- 链上模式：付款钱包、网络与资产、余额、收款地址、转账数量、预计网络费。
- 美元账户模式：本人可用美元、收款人账户 ID、查到的昵称和头像、金额与可选备注。
- 底部展示实际扣款和到账说明；链上网络费与转账币量分别显示。

## 按钮与跳转

| 按钮或操作 | 行为与去向 |
| --- | --- |
| 链上转账／美元账户转账 | 切换模式；已填金额及目标需要重新确认。 |
| 粘贴／扫一扫 | 填写地址或账户 ID；扫描到订单码转入[支付确认](../支付/02支付确认.md)。 |
| 查找收款人 | 按完整账户 ID 查找，展示唯一匹配结果，不以昵称直接付款。 |
| 全部 | 按实际可用余额与费用计算最大可转金额。 |
| 下一步／确认转账 | 先打开确认弹窗，再进行本机验证或外部钱包授权。 |
| 查看结果 | 已提交后进入[账单详情](../记录/02账单详情.md)。 |

## 弹窗与抽屉

- 转账确认展示来源、收款人、网络、金额和费用，按钮为返回修改、确认转账。
- 切换类型导致内容丢失时提示；外部钱包授权由钱包软件展示。

## 状态与边界

- 找不到产品用户、本人账户互转、地址无效或余额不足时禁止提交并说明原因。
- 美元账户转账默认免手续费；普通链上转账默认由付款钱包承担网络费。
- 提交后结果未知进入账单处理中，不再次发送；链上原生币不足时提示补充手续费币。
