# 充值美元余额

[返回产品目录](../../README.md) · [公共交互](../../公共/交互与弹窗.md)

## 用途与入口

从钱包首页或资产详情进入，把已支持的链上资产充值为产品美元余额。

## 页面展示

- 付款钱包、网络、币种和可用数量；输入充值币量并显示预计美元价值。
- 汇率及报价时效、平台代付网络费、预计净入账美元、最低净入账限制。
- 明确到账位置为本人美元余额；提交后展示等待授权、确认中和已入账进度。

## 按钮与跳转

| 按钮或操作 | 行为与去向 |
| --- | --- |
| 选择钱包／资产 | 打开相应抽屉，切换后重新报价。 |
| 全部／重新报价 | 计算可用最大数量，或获取新的报价并重新确认。 |
| 确认充值 | 核对净入账后授权当前链上交易。 |
| 查看充值记录 | 进入本次[账单详情](../记录/02账单详情.md)。 |
| 返回钱包 | 回[钱包首页](01钱包首页.md)，处理仍在后台继续。 |

## 弹窗与抽屉

- 充值确认弹窗展示支付币量、费用及净入账美元，用户可返回修改。
- 费用说明弹窗解释平台先代付、从用户充值金额中扣除，避免误解为免费。

## 状态与边界

- 链上达到通道确认要求后及时入账；钱包返回不表示到账。
- 原型最低净入账 1 美元，实际值可配置；意外少付、小额到账进待处理记录。
- 代付通道未验证或暂停时禁用充值并说明原因，不退化为未告知用户的额外扣费。
- 已提交交易保留原报价；失败或未知状态先查询原记录，不重复充值。
