## 用途与入口

从钱包首页的钱包选择抽屉或账户页进入，管理本设备内置钱包及外部钱包连接。

## 页面展示

- 按内置钱包、外部钱包分组，展示名称、网络、缩略地址、默认标记和连接状态。
- 内置钱包显示备份状态；外部钱包显示已授权网络及会话是否有效。
- 本页账户与美元余额账户分开，移除钱包不会删除平台身份。

## 按钮与跳转

| 按钮或操作 | 行为与去向 |
| --- | --- |
| 设为默认／使用此钱包 | 更新本设备默认选择，返回来源页面时刷新余额。 |
| 创建钱包／导入钱包 | 进入[创建与导入钱包](03创建与导入钱包.md)对应步骤。 |
| 连接外部钱包 | 进入[连接外部钱包](04连接外部钱包.md)。 |
| 钱包行／更多 | 打开详情抽屉，提供重命名、复制地址、备份或断开操作。 |
| 完成 | 返回来源页面，保留当前选择。 |

## 弹窗与抽屉

- 重命名弹窗包含名称和保存按钮。
- 备份入口打开创建流程中的备份步骤，先通过本机解锁。
- 移除内置钱包确认说明仅移除本机访问，要求确认已备份；外部钱包使用断开连接确认。

## 状态与边界

- 外部会话过期显示重新连接；断开后保留历史账单。
- 不能在此显示其他设备是否备份或承诺后端恢复私钥。
- 正在处理的交易不因钱包被移除或断开而取消。
