# 收款

[返回产品目录](../../README.md) · [公共交互](../../公共/交互与弹窗.md)

## 用途与入口

从钱包首页、资产详情进入，页面以“链上收款／美元账户收款”两个标签区分资金去向。

## 页面展示

- 链上收款展示钱包、网络、币种、完整收款地址和地址二维码；默认不指定金额。
- 美元账户收款展示本人昵称、产品账户 ID、账户收款码，说明仅供 DexWallet 用户转美元余额。
- 二维码下方明确收款账户和网络；链上收款不自动充值美元余额。

## 按钮与跳转

| 按钮或操作 | 行为与去向 |
| --- | --- |
| 链上收款／美元账户收款 | 切换收款目标类型。 |
| 钱包／资产 | 打开选择抽屉并重新生成对应收款信息。 |
| 复制地址／复制账户 ID | 复制当前类型的收款标识。 |
| 保存收款码／分享 | 保存或分享包含网络、币种说明的收款卡片。 |
| 查看收款记录 | 进入[账单列表](../记录/01账单列表.md)，预选当前账户的收入。 |

## 弹窗与抽屉

- 钱包及资产选择抽屉；分享使用系统可用的分享面板。
- 首次使用显示简短资金去向说明，可关闭。

## 状态与边界

- 没有链上钱包时可创建、导入或连接，美元账户收款仍可用。
- 首版地址二维码以兼容性为先；扫码方仍须核对网络和币种。
- 保存权限被拒绝时保留复制和分享；此码不是外部钱包配对码。
