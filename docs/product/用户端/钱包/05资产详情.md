# 资产详情

[返回产品目录](../../README.md) · [公共交互](../../公共/交互与弹窗.md)

## 用途与入口

从钱包首页资产行进入，对应一个钱包、一个网络、一种资产。

## 页面展示

- 资产名称、网络、完整余额、参考美元估值、当前钱包地址。
- 交易列表显示收发方向、币量、时间及确认状态，网络费作为独立字段。
- 当前报价时间和数据更新状态；代币可展开查看合约标识。

## 按钮与跳转

| 按钮或操作 | 行为与去向 |
| --- | --- |
| 收款 | 进入[收款](06收款.md)，预选当前网络与币种。 |
| 转账 | 进入[转账](07转账.md)链上模式，预选当前钱包与资产。 |
| 充值美元余额 | 进入[充值](08充值美元余额.md)，使用当前资产作为资金来源。 |
| 交易行 | 进入[账单详情](../记录/02账单详情.md)。 |
| 复制地址／查看浏览器 | 复制本钱包地址或打开当前资产的官方区块浏览器页面。 |

## 弹窗与抽屉

- 资产信息抽屉展示网络、代币标识和小数位等可核对信息。
- 钱包选择抽屉允许切换当前资产对应的钱包，切换后刷新数据。

## 状态与边界

- 没有余额仍允许收款；转账禁用并说明余额不足。
- 代币到账和网络费分开，不用参考美元估值代替真实数量。
- 不提供首版范围外资产的买卖或兑换入口。
