## 用途与入口

从钱包首页头像进入的轻量页面，不新增第四个底部导航。

## 页面展示

- 头像、昵称、产品账户 ID、当前身份来源。
- 钱包管理、账单、语言、产品说明和问题反馈入口。
- 近期处理申请的状态摘要，可关联原账单。

## 按钮与跳转

| 按钮或操作 | 行为与去向 |
| --- | --- |
| 复制账户 ID | 用于美元账户转账和收款。 |
| 钱包管理／全部账单 | 进入[钱包管理](../钱包/02钱包管理.md)、[账单列表](../记录/01账单列表.md)。 |
| 语言 | 打开语言选择抽屉。 |
| 帮助与反馈 | 打开帮助抽屉，资金问题引导先选择相关账单。 |
| 退出登录 | App 退出产品身份；Mini App 提供关闭或重新打开的容器行为。 |

## 弹窗与抽屉

- 语言选择保存本设备偏好。
- 帮助抽屉区分钱包连接、收付款、任务奖励，提供简短说明和问题描述入口。
- 退出确认说明不取消已提交交易，私钥备份按钱包管理规则处理。

## 状态与边界

- 不提供修改邀请上级或领取通用邀请链接的入口。
- 反馈不等于自动退款或发奖；产生处理记录后展示可查询状态。
- 身份恢复与链上钱包恢复分开，找回产品账户不承诺找回本机钱包密钥。
