## 用途与入口

从工作台异常卡、侧栏或资金记录进入，处理真实资金与订单状态不一致的问题。

## 页面展示

- 列表包含充值、付款、提现、退款异常，标记少付、多付、重复、过期到账、无法匹配、链上未知或回调失败。
- 详情抽屉展示订单应收、实收、美元部分、链上部分、交易凭据、报价与处理时间线。
- 展示自动查询或重试次数、最近错误和用户／商户补充说明。

## 按钮与跳转

| 按钮或操作 | 行为与去向 |
| --- | --- |
| 重新查询链上结果 | 读取原交易并更新证据，不再次发送资金。 |
| 重新通知商户 | 仅已确认收款的订单可执行，不改变支付状态。 |
| 关联订单／提交补确认 | 选择目标记录并核对金额、网络、资产与收款方后处理。 |
| 发起差额或原路退款 | 输入可退金额和原因，进入确认及执行流程。 |
| 记录处理结果／暂挂 | 写入原因、下一步和反馈内容；暂挂不消失于待处理视图。 |

## 弹窗与抽屉

- 补确认弹窗展示证据及余额变化预览，无到账证据时不能确认支付成功。
- 退款确认展示原资金来源、可退上限、费用和到账目标。
- 处理说明弹窗区分内部诊断与用户或商户可见结果。

## 状态与边界

- 不得通过“关闭异常”掩盖仍未处理的资金；完成时必须有明确结果。
- 同一链上到账不能关联并记账给两个订单。
- 支付回调失败重试通知；只完成部分付款不能直接通知商户整单成功。
- 异常退款不是任务奖励撤销。
