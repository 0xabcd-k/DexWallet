## 用途与入口

从工作台待办或侧栏进入，处理奖励提现、美元余额出金、商户结算和退款申请。

## 页面展示

- 标签按申请类型分类，筛选待审核、已通过、已拒绝、待补充。
- 列表显示申请人或商户、金额与单位、申请时间、风险摘要和等待时长。
- 详情抽屉展示账户余额、历史统计、关联订单、资金占用、报价及申请原因。

## 按钮与跳转

| 按钮或操作 | 行为与去向 |
| --- | --- |
| 查看申请 | 打开审核详情抽屉。 |
| 通过 | 填写处理说明并确认，进入后续执行，不直接标记到账。 |
| 拒绝 | 填写用户可见原因，确认后按业务规则释放或退回资金。 |
| 要求补充说明 | 将申请转待补充，用户从关联账单提交信息。 |
| 查看关联记录 | 进入[资金与结算](07资金与结算.md)或[异常订单](06异常订单.md)。 |

## 弹窗与抽屉

- 通过确认展示准确金额、收款目标和后续动作。
- 拒绝弹窗要求原因，并展示将退回哪个账户。
- 补充说明弹窗填写所需信息，不要求用户提供私钥或助记词。

## 状态与边界

- 不同申请类型的退款目标分开：奖励回待提现、美元余额回美元余额、商户结算回商户可结算余额。
- 通过时报价过期的出金先请求用户或商户确认新报价，再执行。
- 不对结果不明的链上交易重复审核出金；已处理申请再次点击只返回原结果。
