# 平台商户管理

[返回产品目录](../README.md) · [公共交互](../公共/交互与弹窗.md)

## 用途与入口

平台侧栏商户入口，负责手动开通、查看商户状态及停用。

## 页面展示

- 列表显示商户 ID、名称、状态、联系人、费率方案、可结算金额及最近交易。
- 商户详情抽屉展示接入配置摘要、订单、结算与异常记录入口。
- 新建表单包含名称、联系信息、启用通道及初始管理员账户。

## 按钮与跳转

| 按钮或操作 | 行为与去向 |
| --- | --- |
| 开通商户 | 打开创建抽屉，成功后展示商户资料和初始登录信息。 |
| 商户行／编辑 | 查看或修改可配置资料及费率。 |
| 暂停新交易／恢复 | 确认影响范围，不阻断历史账单查询与既有资金处理。 |
| 查看订单／结算 | 进入对应平台资金或异常页面，携带商户条件。 |
| 重置商户登录 | 确认身份后生成新的恢复方式，记录操作原因。 |

## 弹窗与抽屉

- 创建及编辑抽屉包含保存、取消。
- 停用、恢复、重置登录分别使用操作确认弹窗，说明对新旧订单的影响。

## 状态与边界

- 已支付订单与商户余额不能随停用删除。
- 变更费率只影响新建订单，旧单保留原版本。
- 首版手动开通，不做商户自助入驻审核体系。
