# 平台资金与结算

[返回产品目录](../README.md) · [公共交互](../公共/交互与弹窗.md)

## 用途与入口

平台统一查询资金业务，页内标签为用户资金、商户结算、退款与对账。

## 页面展示

- 按账户、用户、商户、日期、网络、资产、状态或业务编号筛选。
- 记录列出原始金额单位、美元换算、费用、资金来源去向、执行状态和关联订单。
- 对账区显示平台账目与链上记录的匹配结果及未匹配项。
- 链上备付资产按网络与币种显示，不与用户负债余额混成一个可支出总数。

## 按钮与跳转

| 按钮或操作 | 行为与去向 |
| --- | --- |
| 查询／导出 | 查询或导出当前业务范围的资金记录。 |
| 记录行 | 打开详情抽屉，展示完整状态和关联记录。 |
| 进入审核／处理异常 | 分别到[审核中心](05审核中心.md)、[异常订单](06异常订单.md)。 |
| 刷新通道余额／重新对账 | 更新查询结果，显示本次执行状态。 |

## 弹窗与抽屉

- 资金详情抽屉含复制凭据、区块浏览器及关联订单入口。
- 导出和对账弹窗显示范围、生成中与完成状态。

## 状态与边界

- 平台资金执行由后台业务完成，页面不提供直接输入任意地址任意打款的万能按钮。
- 备付不足的出金显示待处理原因，不伪装成已发出。
- 提现拒绝退回、内部余额互转、商户入账等账务变更都能追到原业务记录。
