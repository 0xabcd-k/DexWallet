# 平台参数配置

[返回产品目录](../README.md) · [公共交互](../公共/交互与弹窗.md)

## 用途与入口

平台侧栏配置入口，按业务分标签，保持单人可维护。

## 页面展示

- 资产通道：客户端、网络、币种、充值／付款／提现开关、限额、费用规则。
- 行情报价：数据来源、当前汇率、更新时间、异常状态和报价有效期。
- 风险与提现：当前规则版本、启用条件、阈值及人工处理开关；具体风险函数由业务实现。
- 任务奖励：首奖与 Pro 等已确认常量展示为规则摘要，水果机档位、概率和生效版本可配置。
- 商户与订单：订单有效期、结算最低额、默认费率及通知重试配置。

## 按钮与跳转

| 按钮或操作 | 行为与去向 |
| --- | --- |
| 编辑／保存草稿 | 修改可配置参数，不立即影响在线业务。 |
| 校验／预览影响 | 检查数值、概率合计及必要通道参数，展示影响范围。 |
| 发布配置 | 确认后生成新版本；既有交易按记录保留原规则。 |
| 暂停通道／恢复通道 | 停止或恢复新业务入口；已有交易继续查询和处理。 |
| 查看历史版本 | 打开版本抽屉查看操作者、时间及改动。 |

## 弹窗与抽屉

- 发布确认显示旧值、新值、生效范围与操作者说明。
- 暂停通道弹窗展示用户端提示文案与受影响业务。
- 版本详情抽屉提供只读对比，不以回滚配置撤销既有资金变化。

## 状态与边界

- 概率总和、RTP、负费用或无效限额校验不通过时不能发布。
- 行情不可用时暂停新换算，不能使用未知汇率继续扣款。
- 平台代付功能仅在实际通道验证后启用；不是一个 UI 开关就具备链上代付能力。
- 敏感凭据通过受控配置渠道维护，页面仅展示必要连接状态和诊断信息。
