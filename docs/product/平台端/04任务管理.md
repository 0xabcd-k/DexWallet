# 平台任务管理

[返回产品目录](../README.md) · [公共交互](../公共/交互与弹窗.md)

## 用途与入口

平台侧栏任务入口，配置已经实现的任务类型及上下架状态。

## 页面展示

- 任务列表显示名称、任务类型、奖励积分、有效期、状态和完成统计。
- 编辑抽屉展示多语言标题与说明、执行入口、参与限制和该任务类型支持的专属参数。
- 预览区显示用户卡片、详情页及邀请页的主要文案。

## 按钮与跳转

| 按钮或操作 | 行为与去向 |
| --- | --- |
| 新建任务 | 从已实现类型选择，填写配置；不提供任意代码上传。 |
| 编辑／预览 | 修改尚可变更的字段或预览用户页面。 |
| 发布／下架 | 确认后改变新参与入口可见性。 |
| 查看完成记录 | 按用户、时间和验证状态查看此任务记录。 |

## 弹窗与抽屉

- 新建与编辑使用侧栏抽屉，支持保存草稿、取消。
- 发布确认展示奖励与资格摘要；配置缺失时禁止发布。
- 下架说明弹窗区分停止新参与和已开始任务的处理规则。

## 状态与边界

- 每类任务的完成验证单独开发，运营配置不能代替业务实现。
- 首奖、Pro 翻倍及 20% 分成由公共规则处理，不让任务配置重复发首奖。
- 不提供事后撤销已发积分或分成的操作。
