## 用途与入口

从商户订单列表或概览进入，核对一笔订单的支付、退款和通知过程。

## 页面展示

- 订单标识、标题、应付美元、已收金额、有效期、支付状态。
- 付款组成：美元余额与链上资产，实际网络、币种、币量和适用费用。
- 到账与商户余额变化、回调尝试及最近结果、退款记录和异常说明。

## 按钮与跳转

| 按钮或操作 | 行为与去向 |
| --- | --- |
| 复制支付链接／保存支付码 | 待支付且有效时提供给付款人。 |
| 关闭订单 | 仅尚未开始付款的订单可申请关闭。 |
| 申请整单退款 | 已支付且可退款时填写原因，交平台处理。 |
| 重新通知 | 已收款但回调失败时重试通知，不改变支付状态。 |
| 申请处理／查看处理进度 | 提交订单异常说明或查看已存在的处理结果。 |
| 返回列表 | 保留筛选回[订单列表](02订单列表.md)。 |

## 弹窗与抽屉

- 关闭订单确认提示已开始付款的记录不能简单作废。
- 退款申请弹窗展示可退款金额、原支付来源、费用说明及原因，确认后进入审核。
- 回调详情抽屉展示时间、响应及失败原因；重试有结果反馈。

## 状态与边界

- 商户不能手工标记付款成功或修改已支付金额。
- 已退款、退款中或资金结果不明时，不重复申请同一退款。
- 正常退款首版按整单规划；异常多付差额由平台按记录处理。
