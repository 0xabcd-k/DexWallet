# 创建收款单

[查看页面线框图与交互说明](../图文原型/index.html#m04)（本地浏览器打开）

[返回产品目录](../README.md) · [公共交互](../公共/交互与弹窗.md)

## 用途与入口

从商户概览或订单列表进入，手动生成一笔美元计价订单。

## 页面展示

- 订单标题、美元金额、商户订单号、可选备注和有效期。
- 可接受的网络资产范围与服务费提示；实际选项来自商户和平台已启用通道。
- 创建后原页展示订单号、支付链接、支付二维码、到期时间和状态。

## 按钮与跳转

| 按钮或操作 | 行为与去向 |
| --- | --- |
| 创建收款单 | 校验后生成唯一订单，切换到生成结果区域。 |
| 复制链接／保存二维码 | 分享本订单支付入口。 |
| 查看订单 | 进入[订单详情](03订单详情.md)。 |
| 再建一单 | 进入空白表单；不重复使用已生成订单。 |

## 弹窗与抽屉

- 创建前确认弹窗展示标题、金额和有效期。
- 离开未保存内容使用放弃表单确认。

## 状态与边界

- 同一商户订单号重复时展示已有记录，不重复创建订单。
- 金额为正且符合平台限制；无可用通道时禁用创建。
- 二维码是商户订单码，不是钱包地址或连接配对码。
