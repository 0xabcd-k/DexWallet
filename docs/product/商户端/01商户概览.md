# 商户概览

[返回产品目录](../README.md) · [公共交互](../公共/交互与弹窗.md)

## 用途与入口

商户后台登录后的首页。侧栏提供概览、订单、创建收款单、资金与结算、接入设置。

## 页面展示

- 今日支付金额与笔数、待支付订单数、退款中金额、可结算美元。
- 最近订单、需要处理的退款及结算状态、回调异常提示。
- 显示当前商户名称、启用状态和平台公告；金额口径均为当前商户。

## 按钮与跳转

| 按钮或操作 | 行为与去向 |
| --- | --- |
| 创建收款单 | 进入[创建收款单](04创建收款单.md)。 |
| 查看订单／资金与结算 | 进入对应列表并携带当前指标的筛选条件。 |
| 接入设置 | 进入[接入设置与文档](06接入设置与文档.md)。 |
| 状态卡／最近订单 | 进入[订单详情](03订单详情.md)或对应结算记录。 |
| 退出登录 | 结束商户会话，回[后台登录](../公共/后台登录.md)。 |

## 弹窗与抽屉

- 统计口径说明弹窗解释支付金额、可结算余额和处理中占用。
- 公告抽屉展示影响商户的通道维护，不把用户风险信息展示给商户。

## 状态与边界

- 未启用时提示联系平台，保留已有记录查询，不能创建新订单。
- 无订单时提供接入文档和创建首单入口。
- 首版不提供多门店、多操作员角色管理。
