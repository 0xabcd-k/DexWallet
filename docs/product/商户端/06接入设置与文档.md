## 用途与入口

商户侧栏接入入口，集中管理接入资料和阅读 API 使用说明。

## 页面展示

- 商户名称、商户 ID、开通状态、支付通道及服务费说明。
- 接入凭据、回调地址、支付后返回地址；配置更新时间。
- 文档标签展示创建订单、查询订单、支付结果通知、签名校验、幂等和错误说明；示例不包含真实密钥。

## 按钮与跳转

| 按钮或操作 | 行为与去向 |
| --- | --- |
| 保存设置 | 校验地址等字段并保存当前配置。 |
| 生成／轮换凭据 | 按确认流程创建新凭据，旧凭据停用策略明确展示。 |
| 复制商户 ID／复制示例 | 复制相应内容。 |
| 发送测试通知 | 发送标为测试的事件并显示响应，不伪造真实订单。 |
| 查看文档章节 | 在页内切换章节，不把整套后台规范放进订单页面。 |

## 弹窗与抽屉

- 凭据生成或轮换确认说明影响；生成结果提供一次性完整查看和复制。
- 测试结果弹窗展示请求摘要、响应和耗时，便于商户排查。

## 状态与边界

- 只有当前商户的接入信息可见；凭据默认不持续明文展示。
- 回调失败不撤销已支付订单；商户可主动查单。
- 首版一个主账户，不提供应用市场、插件商城或复杂权限配置。
