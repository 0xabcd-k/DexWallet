# 商户订单列表

[查看页面线框图与交互说明](../图文原型/index.html#m02)（本地浏览器打开）

[返回产品目录](../README.md) · [公共交互](../公共/交互与弹窗.md)

## 用途与入口

商户侧栏订单入口，查询本商户订单及付款结果。

## 页面展示

- 筛选区：日期、订单状态、平台订单号、商户订单号。
- 列表列出订单标题、美元金额、已收金额、退款状态、创建时间及支付时间。
- 回调状态独立列示，不能以回调失败替代支付状态。

## 按钮与跳转

| 按钮或操作 | 行为与去向 |
| --- | --- |
| 查询／重置 | 应用或清除筛选。 |
| 订单行／查看详情 | 进入[订单详情](03订单详情.md)。 |
| 创建收款单 | 进入[创建收款单](04创建收款单.md)。 |
| 导出当前结果 | 生成当前筛选范围的订单报表，展示生成及下载状态。 |

## 弹窗与抽屉

- 导出确认说明时间范围和记录数量，生成后提供下载。
- 日期筛选使用统一选择组件。

## 状态与边界

- 列表只包含当前商户；没有订单与筛选无结果分别提示。
- 处理中订单可刷新但不提供强制成功按钮。
- 导出失败提供重试，不清除筛选结果。
