# 功能盘点
任务列表 初始奖励1美元，继续做任务到2美元，解锁pro，就可以提现并奖励积分翻倍

任务奖励是积分制的 1000积分等于1美元，每100积分转一次，奖励的数学期望为0.1美元*rtp，可能高也可能低。

任务可以自己做也可以邀请别人做

任务都有两个选项，自己做或者邀请别人做

邀请别人做就是复制一个邀请链接，告知邀请好友完成任务，来获得奖励
任务页面会跟据不同情况显示不同的奖励
如果是自己做，就显示任务对应的奖励金额
是帮别人做，如果自己是新用户，那么奖励金额是1美元，如果自己是老用户，那就写一个助力。

邀请逻辑
你邀请新用户自动会成为你的下级，下级后续获得任务奖励时，你可以获得下级奖励的20%积分。

我们应该有这些页面，

任务列表页-列举目前有的任务
    邀请弹窗
    水果机
任务完成页-具体关于任务内容的介绍
分享统计页

钱包页面（此页面应该是首页）
    扫码支付功能 与连接钱包的商户对接，扫了就自动跳转支付页面，前端向此订单付款，后端轮询，然后向商户发起回调

商户向项目后端申请创建一个订单，然后把订单号渲染在前端
用户钱包扫码，从后端拿到订单信息 金额-允许币种-后端钱包地址-订单号
前端用memo记录订单号，付款到对应钱包地址
后端轮询检查钱包地址上的内容，回调商户，将付款信息给过去# 功能盘点
