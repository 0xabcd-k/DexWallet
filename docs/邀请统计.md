# 邀请关系与收益统计需求

[返回产品规划](大纲.md)。关联功能：F06。负责人【待填写】；优先级与目标版本【待填写】；原型【待填写】。

原有设想：邀请的新用户自动成为下级，其后续任务奖励的 20% 作为邀请人的积分奖励；好友完成任务也可能产生助力。原始规则见 R06–R08，以下细化项均待确认。

## 用户目标与概念

用户故事：作为邀请人，我希望知道谁通过邀请加入、哪些任务产生了助力或返佣，以及收益何时可用。

建议分别定义：邀请关系（谁邀请谁）、任务助力（帮哪个任务）、返佣记录（根据哪笔奖励计算）。三者能否同时发生、如何关联【待填写】。

## 邀请与归因规则

| 事项 | 待填写内容 |
| --- | --- |
| 新用户判定 | 身份依据、判定时点、历史账户及换钱包处理 |
| 邀请链接 | 通用或任务专属、邀请人和任务标识、有效期、失效行为 |
| 绑定时点 | 打开链接、建立账户、完成首个任务或其他条件 |
| 多个邀请来源 | 首次或最后一次有效来源；归因窗口；冲突处理 |
| 老用户邀请 | 是否绑定关系，还是只产生一次助力 |
| 关系变更 | 是否允许解绑、更换或纠错；对历史及未来收益的影响 |
| 邀请层级 | 原稿描述直接邀请；是否扩展需单独决策 |
| 自邀与异常 | 同账户、同钱包、循环关系、多账户行为的有效性判断 |
| 跨设备与中断 | 登录后恢复归因、链接信息丢失时的处理 |

## 助力与返佣

| 规则 | 待填写内容 |
| --- | --- |
| 助力有效性 | 触发条件、助力对象、同任务及周期上限、是否可帮多人 |
| 助力结果 | 增加进度、直接完成任务或其他效果；所需助力数量 |
| 返佣基数 | 基础积分、Pro 翻倍后的积分，或其他明确基数 |
| 计入范围 | 新人奖励、水果机奖励、补发奖励是否参与；是否含返佣本身 |
| 成本承担 | 平台额外发放还是从被邀请人奖励中扣除 |
| 精度与上限 | 小数积分如何处理、单人及活动上限、有效期限 |
| 发放时点 | 下级任务完成、奖励入账或其他节点；冻结期 |
| 返佣可用性 | 是否可用于水果机、Pro 进度或提现 |
| 撤销与更正 | 原奖励撤销后如何冲回；已使用或已提现如何处理 |

返佣验算：基础奖励 X【待填写】；Pro 处理后的奖励【待填写】；最终返佣基数【待填写】；应用 R08 后邀请人积分【待填写】；双方账单【待填写】。

## 页面与统计口径

| 指标或区域 | 建议定义 | 待补充 |
| --- | --- | --- |
| 邀请概览 | 按已生效的直接关系统计人数 | 去重、作废和注销处理 |
| 有效邀请 | 已绑定并满足指定有效条件的用户数 | 有效条件及时间归属 |
| 助力记录 | 满足规则的任务助力次数及对象 | 撤销、上限及任务维度 |
| 收益概览 | 待结算、已入账、已撤销分别统计 | 净额口径和可用金额 |
| 收益明细 | 时间、来源任务、奖励基数、返佣、状态 | 详情权限及关联账单 |
| 趋势或筛选 | 时间范围、任务、记录状态 | 时区、刷新延迟、导出是否需要 |

展示哪些被邀请人资料【待填写】；空记录、加载失败、统计延迟和账户受限时的界面【待填写】。不默认向邀请人展示被邀请人的全部资产或无关活动。

## 验收场景草案

| 场景 | 可观察的预期结果 |
| --- | --- |
| 有效新用户首次进入并达成绑定条件 | 关系只生效一次，人数变化符合口径 |
| 同一人打开多个邀请链接 | 按确认后的优先规则归因 |
| 老用户完成助力 | 不误计为新邀请；助力效果正确 |
| 下级获得普通或 Pro 任务奖励 | 返佣基数、舍入和入账与验算一致 |
| 原奖励重复通知或被撤销 | 不重复返佣；撤销与净收益保持一致 |
| 不同日期和状态筛选 | 概览与明细可按同一口径核对 |

处理异常和申诉见[运营与维护](运营与维护.md)，奖励来源见[任务详情](任务详情.md)。
