## 用途与入口

平台侧栏用户入口；列表为页面，单个用户详情使用侧栏抽屉。

## 页面展示

- 按产品账户 ID、外部身份标识或昵称检索；列表显示昵称、账户状态、创建时间、Pro 状态。
- 详情抽屉分基本资料、四类账户、Pro 进度、邀请关系、资金及任务记录。
- 风险摘要显示相关统计与已触发处理记录，便于人工判断。

## 按钮与跳转

| 按钮或操作 | 行为与去向 |
| --- | --- |
| 查询／重置 | 按条件查找用户。 |
| 用户行 | 打开详情抽屉。 |
| 查看账单／审核记录 | 到[资金与结算](07资金与结算.md)或[审核中心](05审核中心.md)并筛选用户。 |
| 限制交易／解除限制 | 填写原因并确认，限制范围明确显示。 |

## 弹窗与抽屉

- 用户详情抽屉包含关联记录的跳转，不提供直接编辑余额按钮。
- 交易限制确认选择影响范围并填写原因；确认结果写入[操作记录](09操作记录.md)。

## 状态与边界

- 不提供任务奖励撤销、任意积分增减或修改邀请上级的首版入口。
- 风险处理不删除用户历史记录；账户余额查询不得包含私钥。
- 只有必要身份与业务信息进入页面，不把敏感凭据写入导出或公开界面。
