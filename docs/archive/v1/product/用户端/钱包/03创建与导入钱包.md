## 用途与入口

从钱包首页或钱包管理进入的多步骤页面；创建、导入两条路径共用钱包名称和完成页。

## 页面展示

- 路径选择显示“创建新钱包”“导入已有钱包”，说明密钥由用户保管。
- 创建路径依次展示钱包名称、本机解锁设置、助记词备份、抽词确认和创建完成。
- 导入路径展示钱包名称、支持的助记词格式和输入区；解析成功后列出支持网络中的可恢复账户供确认。
- 完成页显示新增钱包和地址，不混入平台美元余额。

## 按钮与跳转

| 按钮或操作 | 行为与去向 |
| --- | --- |
| 创建／导入 | 进入对应步骤，不自动覆盖已有钱包。 |
| 查看并备份／已备份，下一步 | 显示备份内容并进入抽词确认。 |
| 验证并导入 | 校验输入，展示实际可恢复的账户。 |
| 完成 | 保存本机钱包并返回原页面。 |
| 改用外部钱包 | 进入[连接外部钱包](04连接外部钱包.md)。 |

## 弹窗与抽屉

- 退出未完成流程弹窗允许继续或放弃。
- 本机解锁弹窗用于再次查看备份内容；操作具体采用平台可用的解锁方式。

## 状态与边界

- 错误助记词显示字段反馈，不伪装成新建成功。
- 不承诺任意其他钱包的助记词能恢复所有账户；不支持的格式说明原因。
- 后端不保存助记词和私钥；此页面不用于连接外部钱包。
